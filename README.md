# Акции во Штип

Скрипта што секој ден ги чита јавните ценовници на маркетите во Штип, ги вади
акциите и промените на цените, ја чува историјата и прави страница што се
отвора на телефон.

Маркетите се должни по закон секој работен ден до 10 часот да ги објават
цените за секоја своја продавница. Скриптата чита токму тие ценовници, по
продавница, не по синџир.

## Што покрива

| Маркет | Извор | Продавници во Штип на 02.10.2026 |
|---|---|---|
| КАМ | `kam.mk`, PDF по продавница | „Штип - 3“ и другите што КАМ ги води во Штип |
| Рамстор | `ramstore.com.mk/marketi/` | Штип, Штип Луна |
| Стокомак | `stokomak.proverkanaceni.mk` | се наоѓа по име при првото читање |
| Жито маркети | `zito.proverkanaceni.mk` | Сењак, 2 Влез, Центар, Градинка |
| Кипер | `kipper.mk` | една, но објавуваше **празен** ценовник |

Што **не** покрива засега:

- **СПАР** (најмногу продавници во Штип). Ценовникот е на `spar.mk/pricelist`,
  но читач не е напишан, зашто не можев да ја видам страницата одвнатре.
  Видете „Додавање нов маркет“ подолу.
- **Кит-Го**. Страницата со нивните ценовници е затворена за автоматско читање
  (robots), па ја оставив настрана.
- **Тинекс**. Изворот `ceni.tinex.mk` не работеше во октомври 2026.

## Што добивате

- `docs/index.html`: страница за телефон со сите акции во Штип. Има пребарување,
  филтри „Нови денес“, „Истекуваат“ и „Мои производи“, избор по маркет и преглед
  на променетите редовни цени.
- **Кошничка по маркети** (на страницата и во `IZVESTAJ.md`): основните производи
  за едно семејство, секој кај маркетот каде што тој ден е најевтин, и колку чини
  целата кошничка ако сè се купи на едно место. Видете „Кошничка“ подолу.
- `IZVESTAJ.md`: краток преглед што се чита директно на GitHub.
- `podatoci/`: историјата, како обични CSV датотеки (се отвораат во Excel).

Две ознаки вреди да се знаат:

- **само со картичка**: цената важи само со картичка за лојалност.
- **редовната цена е покачена**: во последните 45 дена редовната цена на тој
  производ во таа продавница пораснала, па попустот може да е помал отколку што
  изгледа.

## Поставување на GitHub (без сопствен компјутер што работи постојано)

1. Направете ново репо на GitHub. Ако сакате страницата бесплатно преку GitHub
   Pages, репото треба да биде јавно.
2. Качете ја целата содржина на оваа папка, заедно со скриената папка `.github`.
3. Во репото отворете **Actions**, изберете **Дневно читање** и притиснете
   **Run workflow**. Првото читање може да потрае десетина минути или повеќе.
4. Отворете **Settings → Pages**, под „Build and deployment“ изберете
   **Deploy from a branch**, гранка `main`, папка `/docs`. Страницата потоа е на
   `https://<корисник>.github.io/<репо>/`.

Оттаму читањето оди само, од понеделник до сабота околу 10:37 зиме и 11:37
лете. Ако ниту еден ценовник не се прочита, работата завршува со грешка, а
GitHub за неуспешна работа вообичаено праќа е-пошта.

## Пуштање на сопствен компјутер

Треба Python 3.11 или понов.

```
pip install -r requirements.txt
python -m stipakcii
```

Корисни варијанти:

```
python -m stipakcii --samo kam,ramstore    само некои маркети
python -m stipakcii --samo-izvestaj        без мрежа: извештај од запишаното
```

## Поставки

Сè е во `postavki.toml`. Најкорисното е листата `sledi`:

```toml
sledi = ["кафе", "масло сончоглед", "детергент ариел"]
```

Секој запис е еден или повеќе збора што сите мора да ги има називот или описот
на производот.

### Кошничка

Листата `[[kosnicka]]` во `postavki.toml` кажува кои основни производи се бараат:
леб, млеко, јајца, брашно, масло, пилешко, средства за хигиена, храна за кучиња.
За секој од нив скриптата ја наоѓа најевтината понуда во секој маркет, по
килограм, литар или парче, и го става кај маркетот што е најевтин.

```toml
[[kosnicka]]
ime = "Млеко трајно"
bara = ["млеко", "трајно|ухт"]     # сите мора да ги има; „а|б" значи едно од двете
bez = ["чоко", "соја", "лактоз"]   # ако има нешто од ова, се прескокнува
pakuvanje = "1 л"                  # или опсег: "400-500 г", "8-24 парчиња"
nedelno = "6 л"                    # колку троши семејството неделно (проценка)
```

Влегува најевтината стока од тој вид, без оглед на брендот: најевтиното млеко
може да биде со 1,5% маснотија, а најевтината тоалетна хартија двослојна. Затоа
до секоја цена стои и називот. Кога два маркета имаат иста најниска цена,
производот оди кај оној што веќе има повеќе производи, за да се оди на помалку
места.

Неделните количини се проценка за четворица. Од нив се пресметува колку чини
кошничката ако секој производ се купи каде што е најевтин, и колку би чинела
цела во еден маркет.

По промена на листата вреди да се види што навистина фаќа:

```
python -m stipakcii.kosnicka --kandidati 5              сите ставки
python -m stipakcii.kosnicka --kandidati 5 --samo леб   само една
```

## Што се чува

```
podatoci/
  prodavnici.csv                  кои продавници се читаат и како поминало
  sostojba/<маркет>-<продавница>.csv   целиот ценовник; се пребришува секој ден
  promeni/<година>.csv            ред само кога редовната цена се смени
  akcii/aktivni.csv               акциите што важат денес
  akcii/zavrseni-<година>-<месец>.csv  завршени акции, со прв и последен ден
```

Продавница што еден ден не се прочита не се допира: нејзините акции остануваат
како од последното читање уште три дена, со ознака од кој ден се.

## Додавање нов маркет

Читач се пишува врз вистинска страница, не напамет.

1. Во **Actions** пуштете **Сними примерок од страница** и внесете ја адресата на
   ценовникот (на пример `https://spar.mk/pricelist`). Страницата се запишува во
   `primeroci/`.
2. Врз примерокот се пишува модул во `stipakcii/citaci/`, по урнекот на
   постојните, и се додава еден ред во `stipakcii/citaci/__init__.py`.
3. Примерокот оди и во `tests/primeroci/`, со тест што го чита.

## Тестови

```
pip install -r requirements-dev.txt
python -m pytest
```

Тестовите работат врз зачувани примероци од вистинските ценовници, никогаш врз
живи сајтови. Меѓу нив е и едно цело дневно читање со лажна мрежа.

## Што треба да се знае

- Скриптата чита учтиво: пауза од 1,5 секунди меѓу барања кон ист сајт и јасно
  се претставува. Не ја намалувајте паузата.
- Важи цената на каса. Ценовникот на интернет може да доцни или да има грешка.
- Ист производ во различни маркети има различен назив, па скриптата не ги спојува
  производите меѓу маркети. За споредба служи пребарувањето.

## Потекло

цените се на маркетите.
